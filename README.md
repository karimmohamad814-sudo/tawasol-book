## 🚀 البدء السريع

### المتطلبات
- Node.js 14+ 
- MongoDB
- npm أو yarn

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/karimmohamad814-sudo/tawasol-book.git
cd tawasol-book

# تثبيت المكتبات
npm install

# إنشاء ملف .env
cp .env.example .env

# تشغيل الخادم
npm start

# في نافذة أخرى - تشغيل الواجهة
npm run client
```

افتح `http://localhost:3000` في المتصفح

## 🛠️ التقنيات المستخدمة

### Frontend
- HTML5 - البنية الأساسية
- CSS3 - تصميم حديث
- Vanilla JavaScript - بدون مكتبات ثقيلة
- Socket.io Client - للتواصل الفوري
- WebRTC - للمكالمات الصوتية والفيديو
- Service Worker - للعمل بلا إنترنت

### Backend
- Node.js + Express - خادم الويب
- MongoDB + Mongoose - قاعدة البيانات
- Socket.io - التواصل الفوري (Real-time)
- JWT - المصادقة
- Bcrypt.js - تشفير كلمات المرور
- WebRTC Signaling - إشارات المكالمات

## 📝 الاستخدام

### إنشاء حساب
1. اضغط على "إنشاء حساب جديد"
2. أدخل البيانات المطلوبة
3. اختر صورة شخصية
4. اضغط تسجيل

### البدء في المحادثة
1. سجل دخول
2. ابحث عن المستخدم
3. اضغط لفتح المحادثة
4. اكتب الرسالة واضغط إرسال

### إجراء مكالمة
1. افتح محادثة المستخدم
2. اضغط على أيقونة المكالمة (☎️ أو 🎥)
3. انتظر الرد أو اقبل الاتصال
4. انقر على إنهاء لإنهاء المكالمة

### إنشاء جروب
1. اضغط على "إنشاء جروب"
2. أدخل اسم الجروب
3. اختر الأعضاء
4. اضغط إنشاء

## 🔐 الأمان

- جميع كلمات المرور مشفرة باستخدام Bcrypt
